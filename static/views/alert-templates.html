SMS Templates

These are the messages sent when a site goes down, stays down, comes back, or keeps dropping. The same text goes out by SMS, WhatsApp and in the app.

Click a label under a box to insert it — for example {{SITE_NAME}} becomes the site's name when the message is sent. The line under each box shows how it will read with example values.

When alerts are sent

Alerts are only sent inside these hours (Nairobi time). If a site is still down when the hours start, you get one reminder then. Sites that have been acknowledged are never included in the "send battery" list.
